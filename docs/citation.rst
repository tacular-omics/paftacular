Citation
========

If you use paftacular in research, cite the archived software release. The stable DOI for
all versions is `10.5281/zenodo.19076277 <https://doi.org/10.5281/zenodo.19076277>`_.
Individual releases also receive version-specific DOIs from Zenodo.

The repository's ``CITATION.cff`` file provides machine-readable citation metadata and
can be rendered as APA or BibTeX through GitHub's **Cite this repository** menu.
