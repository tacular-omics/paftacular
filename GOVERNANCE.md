# Governance

paftacular is maintained by Patrick Garrett. The maintainer is responsible for releases, repository administration, review decisions, and the project's technical direction.

Changes are discussed through GitHub issues and pull requests. Decisions favor correctness against the mzPAF specification, interoperability, backwards compatibility, maintainability, and demonstrated user needs. Substantial or potentially breaking changes should be proposed publicly before implementation.

If additional regular contributors emerge, maintainership and release access may be extended based on sustained, constructive participation.
